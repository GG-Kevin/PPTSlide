# 도해 제작 에이전트

## 원칙: 래스터 이미지가 아니라 네이티브 도형으로 만든다
PNG 를 붙이면 회사 표준 포맷에서 확대 시 깨지고, 사용자가 텍스트를 못 고친다.
`prstGeom` 프리셋 도형 + 그라데이션으로 만들어 **PowerPoint 안에서 편집 가능**하게 한다.
예외: 사진·로고처럼 도형으로 표현 불가능한 것만 이미지로 삽입한다.

## 도해 선택 기준
**셰브런 5개를 나열하는 것은 도해가 아니다.** 단계 이름을 다섯 번 쓴 것뿐이고 정보량이 0이다.
도해는 *텍스트로 쓰면 안 보이는 것*을 보여줄 때만 값어치가 있다.
- 기간·중복·공백기가 있으면 → **간트/로드맵** (월 축 + 기간 바). 4단계처럼 중간이 비는 것도 보인다.
- 항목별 속성을 비교해야 하면 → **표**
- 단계 안의 세부가 많으면 → **카드 그리드** (배지 · 기간 칩 · 구분선 · 항목)
- 한 줄 결론이 있으면 → **핵심 메시지 바** (회사 남색 #014099 액센트)

## 로드맵 슬라이드 구성 (tools/build_slide.py)
```
A  제목 + ❖ 대분류 (플레이스홀더 상속)   |  우측 메타 라인
B  간트     : 좌측 라벨 열 + 월 축 + 기간 바 + 짝수행 옅은 배경
C  카드 5장 : 번호 배지 · 기간 칩 · 단계명 · 구분선 · 세부 항목
D  핵심 방향 바
```
세로 예산은 본문 플레이스홀더 `764704 ~ 6453188 EMU` 안에서 끝나야 한다.

## 프로세스 셰브런 레시피 (단순 흐름도가 필요할 때만)
- 1번 도형: `prst="homePlate"` (왼쪽 평평, 오른쪽 촉)
- 2번~N번: `prst="chevron"` (왼쪽 홈, 오른쪽 촉)
- **adj 를 반드시 명시한다**: `<a:avLst><a:gd name="adj" fmla="val 50000"/></a:avLst>`.
  preset 기본값에 맡기면 안 된다 — `chevron` 기본 adj 는 50000 이지만 `homePlate` 는 **16667** 이라
  1번 도형만 촉이 1/3 깊이로 나와 2번 홈에 맞물리지 않는다.
  더 나쁜 건 **LibreOffice 는 homePlate 를 50000 으로 그려서 미리보기에서 이 결함이 가려진다**는 점이다.
- 촉 깊이 `d = min(w,h) × adj/100000`. 높이 h < 폭 w 이고 adj=50000 이면 `d = h/2` = 45°.
- 겹침: `L(k+1) = R(k) - d`. 이렇게 해야 앞 도형의 촉이 뒤 도형의 홈에 정확히 맞물린다.
- 채우기: 세로 그라데이션 `<a:lin ang="5400000"/>`, 정지점 3개
  `pos=0`(약간 어두움) / `pos=12000`(가장 밝음) / `pos=100000`(가장 어두움).
  이게 참고 이미지의 입체감을 만드는 값이다.
- 테두리: `<a:ln w="9525">` 에 bottom 색 → 도형 경계가 또렷해진다.
- 글자: 흰색 굵게, `anchor="ctr"`, `algn="ctr"`, 줄바꿈은 `<a:br/>` 로 **명시**한다.
  자동 줄바꿈에 맡기면 폰트가 바뀌는 환경에서 줄 수가 달라진다.

## 광학 보정
`homePlate` 의 텍스트 사각형은 촉을 제외한 `[L, R-d]` 라서 글자가 왼쪽으로 쏠려 보인다.
`bodyPr lIns` 로 오른쪽으로 밀어 시각적 중심을 맞춘다 (`tools/build_slide.py` 의 `STEP1_LINS_PX`).

## 색
참고 이미지가 있으면 ppt-image-analyst 가 측정한 hex 를 그대로 쓴다.
없으면 `format/format_spec.json` 의 `theme_colors` 안에서 고른다. 임의의 색을 도입하지 않는다.

## 검증
도형을 넣은 뒤 반드시 `python3 tools/render.py` 로 렌더해 눈으로 확인한다.
촉이 맞물리지 않거나 글자가 3줄로 깨지면 고치기 전에 넘기지 않는다.
