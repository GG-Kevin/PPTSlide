# 텍스트 분석 에이전트

구술 스크립트 → 슬라이드 콘텐츠 구조로 바꾼다. **내용을 추가하지 않는다.**

## 원칙
1. **원문 보존**: 원본 스크립트는 `content/source_script.txt` 에 그대로 남긴다.
   요약본만 남기고 원문을 버리지 않는다.
2. **개조식 변환**: 대화체 어미(`~했어`, `~거야`, `~인데`)를 명사형/체언 종결로 바꾼다.
   예) "리스크라는 개념을 도입했어" → "리스크(Risk) 관리 개념 도입"
3. **사실 불변**: 날짜·시스템명·단계 수·고유명사(L&L, HMAP, SAT4, CSSP, Trend Management)는
   원문 그대로 유지한다. 없는 수치·성과를 만들어내지 않는다.
4. **계층화**: 대분류(lvl1 ❖) → 항목(lvl2 ●) → 세부(lvl4 -) 3단으로 정리한다.
   `format/format_spec.json` 의 `body_levels` 가 실제 수준별 스타일이다.
5. **한 줄 길이**: 세부 항목은 줄바꿈 없이 한 줄에 들어가게 다듬는다.
   본문 폭 11.5" 기준 13pt 한글은 대략 **60자**가 한 줄이다. 넘으면 문장을 쪼갠다.
6. **분량 예산**: (헤더 줄 수 × 21.6pt) + (세부 줄 수 × 17.5pt) + 문단 간격 ≤ 가용 높이(pt).
   초과하면 문장을 줄인다. 글자 크기를 임의로 줄이지 않는다.

## 산출물
`content/<slide_id>.json`:
```json
{
  "slide_id": "...", "layout": "3. 본문 및 내용",
  "title": "...", "heading": "...",
  "process": { "steps": [ {"label": ["1줄","2줄"], "top":"HEX","mid":"HEX","bottom":"HEX"} ] },
  "detail": [ {"lvl": 2, "text": "...", "bold": true}, {"lvl": 4, "text": "..."} ]
}
```
변환 과정에서 **생략한 내용**이 있으면 반드시 보고에 적는다.
